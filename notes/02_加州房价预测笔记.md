# 加州房价预测：回归、模型比较与交叉验证

## 1. 项目目标

根据街区层面的 8 个输入特征，预测房屋价值中位数。这是有监督回归任务：输出不是类别，而是连续数值。

数据有 20,640 条记录。目标 `MedHouseVal` 以 10 万美元为单位，因此预测值 `2.5` 大约表示 25 万美元。数据来自 1990 年人口普查，只适合教学，不代表今天的市场。

## 2. 八个输入特征

| 特征 | 含义 |
| --- | --- |
| `MedInc` | 街区收入中位数 |
| `HouseAge` | 房屋年龄中位数 |
| `AveRooms` | 平均房间数 |
| `AveBedrms` | 平均卧室数 |
| `Population` | 街区人口 |
| `AveOccup` | 平均居住人数 |
| `Latitude` | 纬度 |
| `Longitude` | 经度 |

这些是街区汇总特征，不是某一套房屋的详细信息。模型预测的是统计关系，不应被解释为因果关系。

## 3. 训练集和测试集

```python
train_test_split(X, y, test_size=0.3, random_state=42)
```

70% 用于训练，30% 留作最终测试。固定 `random_state` 使划分可以复现，便于公平比较模型。

所有候选模型使用同一份划分，否则成绩差异可能来自不同试题，而不是模型能力。

## 4. 为什么比较四种模型

### 线性回归

假设预测值是特征的加权和。优点是简单、速度快、容易作为基线；缺点是难以表达复杂非线性关系。

### KNN 回归

找到距离新样本最近的若干训练样本，用它们的目标值平均作为预测。它依赖距离，因此特征尺度非常重要。

### 决策树回归

不断用条件切分数据，例如“收入是否小于某值”。它能表达非线性和特征交互，不要求标准化，但容易过拟合。

### 神经网络回归

通过多层非线性变换学习复杂关系。它通常需要特征缩放，对超参数和随机初始化更敏感。

这四个模型不是为了选出永远最好的算法，而是建立“先用多个合理基线，再用数据比较”的工作习惯。

## 5. 为什么有些模型要标准化

假设人口数以千计，而纬度只变化几十。如果直接计算距离或梯度，大数值特征可能不合理地支配模型。

```python
Pipeline([
    ("scaler", StandardScaler()),
    ("model", KNeighborsRegressor(n_neighbors=5)),
])
```

`StandardScaler` 大致把特征变成均值 0、标准差 1。KNN 和神经网络需要它；决策树通过阈值切分，缩放前后顺序不变，所以通常不需要。

Pipeline 的更深层价值是防止泄漏：每次训练或交叉验证时，缩放器只在当前训练数据上拟合。

## 6. 三个核心回归指标

### MSE：均方误差

把每个预测误差平方后求平均：

```text
MSE = 平均值((真实值 - 预测值)²)
```

它会特别惩罚大误差，但单位是目标单位的平方，不够直观。越小越好。

### RMSE：均方根误差

```text
RMSE = √MSE
```

RMSE 回到了目标原来的单位。例如 RMSE `0.5161`，在本数据的单位下可粗略理解为约 5.16 万美元的典型误差尺度，但不能把它当作每个样本都固定误差这么多。

### R²：决定系数

R² 衡量模型比“始终预测训练目标均值”好多少：

- `1`：完美预测。
- `0`：大致等于只预测均值。
- 小于 `0`：比均值基线还差。

R² 不是“预测正确率”。原最佳模型的 R² `0.7971`，不应表述成“79.71% 房价预测正确”。

## 7. 基础四模型结果

原 notebook 的一次运行：

| 模型 | 训练 MSE | 测试 MSE | 测试 RMSE | 测试 R² |
| --- | ---: | ---: | ---: | ---: |
| 神经网络 | 0.3033 | 0.3126 | 0.5591 | 0.7618 |
| 决策树 | 0.2188 | 0.4156 | 0.6447 | 0.6834 |
| KNN | 0.2800 | 0.4295 | 0.6554 | 0.6728 |
| 线性回归 | 0.5234 | 0.5306 | 0.7284 | 0.5958 |

读表时先看测试指标判断泛化，再比较训练和测试的差距。

- 线性回归训练与测试接近，但总体误差较高：更像欠拟合。
- 决策树训练 MSE 很低，测试 MSE 明显上升：存在较强过拟合迹象。
- 基础神经网络测试表现最好，且训练/测试差距较小。

不要因为一次结果就断言某种模型永远更好。数据划分、参数、软件版本和随机性都会影响数值。

## 8. K 折交叉验证

只用一次验证划分，结论可能碰巧依赖这次划分。5 折交叉验证把训练数据分成 5 份：

1. 其中 4 份训练，1 份验证。
2. 轮换验证份，共训练 5 次。
3. 对 5 次验证成绩求平均。

这样能更稳定地估计某组超参数的表现，但计算量也约增加 5 倍。

## 9. 网格搜索在做什么

项目比较：

- 隐藏层：`(50,)`、`(50, 50)`、`(50, 50, 50)`
- 激活函数：`relu`、`tanh`、`logistic`

共有 `3 × 3 = 9` 个组合，每个做 5 折，所以至少训练 `9 × 5 = 45` 次。GridSearchCV 最终还会在全部训练数据上重新拟合最佳组合。

评分写成 `neg_mean_squared_error`，是因为 scikit-learn 的搜索接口统一选择“越大越好”的分数。它保存的是负 MSE，展示时要加负号转回正数。

## 10. 为什么调参不能使用测试集

如果你根据测试成绩选择隐藏层或激活函数，测试集就参与了决策。最终再报告同一测试集成绩，会产生乐观偏差。

正确顺序：

```text
训练数据 → 交叉验证选超参数 → 固定最佳模型 → 测试集只评估一次
```

原实验选出的最佳组合是三层 `(50, 50, 50)` 和 `tanh`：

- 5 折平均验证 MSE：`0.2926`
- 最终测试 MSE：`0.2664`
- 最终测试 RMSE：`0.5161`
- 最终测试 R²：`0.7971`

相比基础神经网络，调参后测试 MSE 从 `0.3126` 降到 `0.2664`。这说明有改善，但不代表网格中的选择已经最优。

## 11. 模型能否用于真实房价决策

不能直接使用，至少有这些限制：

- 数据来自 1990 年，分布已经变化。
- 特征是街区聚合值，不是房屋级信息。
- 目标存在上限截断，极高房价难以准确表达。
- 纬度和经度可能让模型间接学习地区差异，也可能延续历史偏差。
- 缺少装修、学区、利率、交易时间等重要变量。
- 离线指标不能代替业务成本、稳定性和公平性评估。

“模型在测试集上表现好”只说明它在当前数据和划分下具有一定预测能力，不代表因果正确、长期稳定或适合高风险决策。

## 12. 常见错误

1. 在完整数据上先标准化，再划分训练/测试数据。
2. 用测试集选择模型或超参数。
3. 把 R² 当作准确率。
4. 只报告测试分数，不比较训练分数。
5. 比较模型时使用不同数据划分。
6. 看到经纬度相关性就解释成因果关系。
7. 网格搜索范围很小，却声称找到了全局最优参数。

## 13. 建议实验

1. 把决策树 `max_depth` 改为 3、5、20、None，观察过拟合变化。
2. 比较 KNN 的 `n_neighbors=3, 5, 10, 20`。
3. 删除经纬度后重新训练，观察性能变化并思考原因。
4. 为线性回归增加 Ridge 和 Lasso。
5. 绘制真实值与预测值散点图、残差图。
6. 使用 RandomForestRegressor 或 HistGradientBoostingRegressor 建立更强基线。
7. 记录交叉验证均值和标准差，不只看第一名。

## 14. 一分钟复述

房价项目用 8 个街区特征预测连续目标。线性回归是简单基线，KNN 依赖距离，决策树容易过拟合，神经网络能学习非线性。KNN 和神经网络要在 Pipeline 中标准化以避免泄漏。MSE 与 RMSE 越小越好，R² 衡量相对均值基线的改进。模型选择和调参只能使用训练数据，测试集应留到最后。好成绩不代表因果关系，也不意味着能直接用于真实房产决策。
