# MNIST 手写数字识别：从像素到分类结果

## 1. 项目目标

模型接收一张手写数字图片，输出 0～9 中最可能的类别。这是一个有监督、多分类任务：训练阶段既有图片，也有正确标签。

这里使用的是全连接前馈神经网络（FNN），在 scikit-learn 中对应 `MLPClassifier`。它是理解神经网络训练流程的好起点，但不是图像任务的最终方案。

## 2. 先读懂数据

```text
x_train: (60000, 28, 28)  训练图片
y_train: (60000,)         训练标签
x_test : (10000, 28, 28)  测试图片
y_test : (10000,)         测试标签
```

图片使用 `uint8` 保存，每个像素是 0～255 的整数。0 通常表示黑色背景，较大数值表示更亮的笔画。标签是 0～9 的整数，不需要手工转成 one-hot 向量，因为 `MLPClassifier` 可以直接处理类别编号。

### 为什么除以 255

```python
x = x.astype(np.float32) / 255.0
```

处理后像素大致落在 `[0, 1]`。较一致的数值尺度能让梯度优化更稳定。先转换成浮点数也能避免整数运算带来的问题。

### 为什么展平

一张图片原来是 `28 × 28`，而全连接层希望每个样本是一行特征：

```python
x = x.reshape(x.shape[0], -1)
```

`28 × 28 = 784`，所以形状变成 `(样本数, 784)`。展平没有丢掉像素值，但丢掉了“哪些像素彼此相邻”的显式结构。这也是卷积神经网络通常更适合复杂图像的原因。

## 3. 数据如何划分

原 notebook 将 60,000 张原始训练图片按 80%/20% 划分：

- 外部训练集：48,000
- 外部验证集：12,000
- 独立测试集：10,000

`stratify=y_train_full` 会尽量保持各数字类别在两部分中的比例一致。对于分类问题，这是一个很有用的习惯。

模型还设置了 `early_stopping=True` 和 `validation_fraction=0.10`。这意味着 `MLPClassifier` 会从传给 `fit()` 的 48,000 条记录中再拿出约 10% 作为内部早停验证数据。因此项目里实际上存在两层验证：

- 内部验证：决定何时停止训练。
- 外部验证：训练结束后独立计算 Accuracy 和 Log Loss。

理解这一点很重要，否则容易误以为全部 48,000 条数据都参与了权重更新。

## 4. 网络结构

```python
MLPClassifier(
    hidden_layer_sizes=(128,),
    activation="relu",
    solver="adam",
    learning_rate_init=0.001,
)
```

可以把网络想成：

```text
784 个输入像素 → 128 个隐藏神经元 → 10 个类别概率
```

### `hidden_layer_sizes=(128,)`

括号中的一个数字表示一个隐藏层，层内有 128 个神经元。注意 `(128,)` 末尾的逗号表示它是单元素元组。

### 参数量

- 输入到隐藏层：`784 × 128` 个权重，加 128 个偏置。
- 隐藏层到输出层：`128 × 10` 个权重，加 10 个偏置。
- 总参数量：`784×128 + 128 + 128×10 + 10 = 101,770`。

这说明模型虽然代码很短，但实际要学习十万多个数值。

### ReLU

ReLU 可写作 `max(0, x)`。它让网络能够学习非线性关系，同时计算简单、梯度传播通常较稳定。

### Adam 和学习率

Adam 根据梯度更新权重。学习率 `0.001` 控制每次更新的步幅：过大可能震荡，过小可能学习缓慢。

### Batch Size

`batch_size=64` 表示模型每次使用 64 个样本估计一次梯度，而不是一次处理全部训练数据。

## 5. 训练到底发生了什么

每一轮大致包含：

1. 前向传播，得到 10 个类别的概率。
2. 用真实标签计算损失。
3. 反向传播，计算每个参数对损失的影响。
4. Adam 更新权重。
5. 在内部验证数据上检查是否继续改善。

原 notebook 在第 18 轮停止，最终训练损失约 `0.0091`。停止原因不是达到 `max_iter=30`，而是验证分数连续 5 轮没有足够改善。这正是早停的作用：节省训练时间，也减少继续记忆训练数据的风险。

## 6. 如何读指标

### Accuracy

准确率等于预测正确数量除以样本总数。原运行结果：

- 验证准确率：`0.9760`
- 测试准确率：`0.9759`

二者非常接近，说明这次实验没有出现明显的验证/测试落差。

### Log Loss

Log Loss 不只关心类别对不对，还关心模型给出的概率是否合理。自信地预测错会受到更大惩罚。

- 验证 Log Loss：`0.0878`
- 测试 Log Loss：`0.0783`

准确率适合快速理解，Log Loss 更能反映概率质量。

### Precision、Recall、F1

对某个数字类别：

- Precision：被模型判为这个数字的样本中，有多少真的属于它。
- Recall：所有真实属于这个数字的样本中，有多少被找出来。
- F1：Precision 和 Recall 的调和平均。

原结果中数字 8 的 Precision 为 `0.9548`，低于多数类别。这提示我们下一步应查看混淆矩阵和具体误判图片，而不是只看总准确率。

## 7. 预测概率和最终类别

```python
probabilities = model.predict_proba(sample)[0]
predicted_class = np.argmax(probabilities)
confidence = np.max(probabilities)
```

`predict_proba()` 返回 10 个概率，`argmax` 找到最大值的位置。最高概率可以叫模型置信度，但它不等于“真实正确概率”；神经网络可能过度自信，概率校准是更进一步的话题。

## 8. 常见错误

1. **忘记除以 255**：优化可能变慢或不稳定。
2. **训练和测试处理不一致**：例如只归一化训练集。
3. **把测试集拿来调参**：最终成绩会过于乐观。
4. **形状不正确**：MLP 需要二维特征矩阵 `(n_samples, n_features)`。
5. **修改多个超参数后只比较一次**：无法知道是哪项改动产生效果。
6. **只看 Accuracy**：类别不平衡或错误代价不同的时候会误导。

## 9. FNN 的边界

FNN 把每个像素当作独立位置。数字稍微平移、旋转或书写风格变化时，它需要重新学习许多组合。CNN 通过局部卷积和权重共享，更擅长提取边缘和局部图案。

因此这里的结论不是“FNN 最适合图像”，而是：MNIST 比较简单，FNN 已能提供强基线，并让我们看清完整分类流程。

## 10. 建议实验

按顺序进行，每次只改一项并记录结果：

1. 把隐藏神经元从 128 改成 32、64、256。
2. 比较学习率 `0.0001`、`0.001`、`0.01`。
3. 关闭早停，观察训练损失和验证准确率。
4. 增加混淆矩阵，找出最容易混淆的数字对。
5. 显示预测错误且置信度最高的 20 张图片。
6. 用标准化或 PCA 处理特征，再比较速度和准确率。

完成前四项后，你应能回答：模型容量、优化速度、过拟合和错误分析之间有什么关系。

## 11. 一分钟复述

MNIST 项目把 28×28 图片归一化并展平为 784 个特征，用带 128 个隐藏神经元的 MLP 做十分类。训练集用于学习权重，验证集用于检查泛化，测试集只做最终评估。准确率衡量预测对错，Log Loss 还衡量概率质量。FNN 能达到约 97.6% 测试准确率，但展平会弱化空间结构，复杂图像通常更适合 CNN。
